# outfit-builder

Build outfits from photos of your own clothes: add pieces to a wardrobe, drag them onto a canvas, and save outfits into folders. Everything is stored in the browser (IndexedDB); there's no server or account.

```bash
cd app
npm install
npm run dev
```

See [`app/README.md`](app/README.md) for tests, builds and deploying.

## Contents

- `app/`: the app (Vite + React + TypeScript)
- `BUILD_SPEC.md`: the full spec (screens, behavior, data model, saving, and the "done when" checklist)
- `design-mockups/`: seven static mockups, numbered in the order a user meets them
- `reference/original-wardrobe-designer.html`: the original single-file app this redesigns
